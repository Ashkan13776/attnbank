    Sparse Transformer¶

    The strided and fixed factorized patterns.

    key
    strided · ab.build("strided")
    category
    restrict
    objective
    approximate — targets fidelity to dense softmax; judged by output error

    What it changes¶

    Every category in the bank changes one object in the reference operator \(y(q)=\int v\,\mathrm{d}\pi_q\); this method changes the support of \(\pi_q\), which shrinks to \(S_q \subseteq \{1,\dots,n\}\) and is renormalised on it. The values \(v\) are untouched, so the whole error is distributional.

    It pursues approximation: it is trying to be dense softmax, so it is fair to judge it by output error, and it must supply a correctness anchor saying where it becomes exact.

    What it declares¶

    Each row is a commitment the conformance suite tests, not a description.

    attribute declared what that commits it to
    supports_causal yes causal=True masks so query \(i\) sees keys \(0 \dots i + (n-m)\).
    expresses_weights yes it can name \(\widehat\pi_q\) on the original \(n\) positions, so it enters the error decomposition.
    row_stochastic yes those weights are \(\ge 0\) and sum to one: \(\widehat\pi_q\) is a probability measure.
    head_independent yes each head is computed from its own \(K, V\).
    trainable no no learned parameters — what you build is what the paper describes.

    Correctness anchor¶

    Exact limit. Built with stride=1 this method provably is dense softmax, and tests/test_conformance.py asserts it — output and weights, float32 and float64.

    >>> ab.describe("strided").limit_config
{'stride': 1}

    Cost model¶

    Analytic, per (batch, head). At \(m = 1024\), \(n = 1024\), \(d = 64\), \(dv = 64\) and bytes_per_el=2, against the reference operator at the same shape:

    quantity this method softmax ratio
    flops 68,419,584 268,435,456 0.255×
    state_bytes 262,144 262,144 1×
    bytes_moved 68,681,728 4,718,592 14.6×

    Counted operations and resident bytes, not measured time — a cost model is not a benchmark. These are what the monograph's capacity arguments are made of; examples/08_cost_and_capacity.py walks the comparison through properly.

    The numbers are the method's own cost(), evaluated — the declaration, not a measurement:

    def cost(self, m, n, d, dv, bytes_per_el=2):
    l, blocks = self.stride, (n + self.stride - 1) // self.stride
    # strided: l + 1 local and one key per block; fixed: one block and c per block
    kept = min(n, l + 1 + blocks if self.pattern == "strided"
               else l + max(self.c, 1) * blocks)
    return {"flops": 2 * m * kept * (d + dv),
            "state_bytes": n * (d + dv) * bytes_per_el,   # the column heads reach back
            "bytes_moved": (m * d + m * kept * (d + dv) + m * dv) * bytes_per_el}

    Backends¶

    reference only, and that is the correct answer. It reports the omitted mass eps (and the \(\chi^2\) divergence of the renormalisation) in extras, which needs the full score matrix. A kernel that avoids materialising that matrix is a kernel that cannot produce them.

    reference is plain PyTorch — the correctness anchor and the default. Declaring a second backend is a claim that it equals the first, checked by tests/test_conformance.py::test_backend_equivalence; declaring sdpa here would be pretending. See Backends.

    Diagnostics returned in extras: c, chi2, eps, k_realized, n_local, n_periodic, pattern, stride, support.

    Configuration¶

    parameter default
    stride 4
    pattern 'strided'
    c 1

    stride: the paper's l. pattern: 'strided' or 'fixed'.

    c: the width of the summarising column of the 'fixed' pattern; ignored by 'strided'.

    ab.describe("strided") returns the same keys alongside everything else this page states.

    Run it¶

    import torch, attnbank as ab

torch.manual_seed(0)
b, h, n, d = 1, 2, 64, 32
q, k, v = (torch.randn(b, h, n, d) for _ in range(3))

attn = ab.build("strided", stride=4, pattern='strided')
out = attn(q, k, v, causal=True,
           return_weights=True)

print(attn)
print(out)
print("invariant W:", out.check_invariant(v))

# objective = approximate: it targets dense softmax, so it is judged by
# output error -- split into the distributional and value terms.
row = ab.compare(["strided"], q, k, v, causal=True,
                 configs={"strided": {'stride': 4, 'pattern': 'strided'}})[0]
print({key: round(row[key], 5) for key in
       ("output_error", "distributional_error", "value_error", "tv")})

    In the paper's notation¶

    monograph sec:sparse-fixed

    Child et al. (2019, Sec. 4.3) factor the attention matrix into two heads whose index sets are, for query i and stride l,

    strided:   A_i^(1) = {t, ..., i},  t = max(0, i - l)
           A_i^(2) = {j : (i - j) mod l = 0}

fixed:     A_i^(1) = {j : floor(j/l) = floor(i/l)}
           A_i^(2) = {j : j mod l in {l - c, ..., l - 1}}

    with l ~ sqrt(n) and c a small integer (8, 16 or 32 in the paper, for l = 128 or 256). The strided pattern suits data with a natural period — it is the one-dimensional reading of attending to the previous row and the same column of an image — and the fixed pattern suits data without one, where "specific cells summarize previous locations and propagate that information to all future cells".

    This method takes the union A_i^(1) u A_i^(2), which is what a single restricted layer can see; the paper's own alternative of giving one head each is a statement about depth, and the bank's unit of measurement is one operator. Both components are stated relative to the query position and then intersected with the mask, so the two-sided reading used in a bidirectional model collapses to Child et al.'s autoregressive sets under causal=True and nothing in the future is ever reachable.

    Offset 0 is in both patterns (j = i satisfies (i - j) mod l = 0 and lies in the query's own block), so every row keeps at least the diagonal. stride = 1 makes A^(2) the whole row under either pattern, which is the exact limit.

    Values are untouched: the error is eps_q (m_{S^c} - m_S) (prop:sparse-identity). Against longformer this isolates what a periodic support buys over a contiguous one at the same budget — the two keep O(l + n/l) and O(w) keys respectively.
