    Browse the bank¶

    The registry, one row per method — 78 rows, grouped by the taxonomy's seven categories. A row leads with the name a method is known by; under it, in monospace, sits the registry key — what you pass to ab.build(...), and where the method's own page is filed. Search matches both, and also the summary, the config keys, the backends, and the papers a method cites — title, first author, BibTeX key. The view you build — search, filters, sort, selection — is held in the URL, so it is a link you can paste.

    5 of the 78 are oracles — lowrank_logit, nmf_oracle, svd_oracle, topk, value_topk — upper bounds on what a mechanism can achieve, not practical methods: you cannot show that a selection is suboptimal without computing what the optimal selection would have been. Each is tagged oracle below and carries a banner on its own page.

    The same thing, in Python¶

    import attnbank as ab

print(ab.list_methods("restrict"))                 # a readable table
ab.list_methods().filter(objective="modify", causal=True).names
ab.method_table()                                  # one JSON row per method
ab.describe("performer")                           # everything one method declares
ab.backend_matrix("sdpa")                          # who claims a fused path
