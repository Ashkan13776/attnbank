    Browse the bank¶

    32 methods, every one of them introspectable. The table below is the registry — ab.list_methods() prints the same rows in a terminal, and ab.method_table() returns them as JSON. Each row leads with the name the method is known by and carries its registry key underneath, because the key is what you pass to ab.build(...) and what the method's own page is filed under.

    Searching matches both of those, plus the summary, the category, the objective, the backends, the config keys, the BibTeX keys, and words you would plausibly type instead of a flag — causal, trainable, oracle, signed. Press / to jump to the box. Tick two to four rows to put them side by side, and the rows where the selected methods declare the same thing fold away, so what is left is the difference. Whatever you search, filter, sort or select is in the address bar, so the view you are looking at is a link you can paste.

    All of that is plain client-side JavaScript over the table that is already on the page: with scripting off you get all 32 rows, sorted by category, every column filled, which is the whole content — there is nothing here to hydrate and nothing to fetch.

    Three of these are oracles

    value_topk, nmf_oracle and svd_oracle are upper bounds on what a mechanism can achieve, not practical methods — you cannot show that top-\(k\) selection is suboptimal without computing what the optimal selection would have been. They are tagged oracle in the table and carry a banner on their own pages.

    The same thing, in Python¶

    import attnbank as ab

print(ab.list_methods("restrict"))                 # a readable table
ab.list_methods().filter(objective="modify", causal=True).names
ab.method_table()                                  # one JSON row per method
ab.describe("performer")                           # everything one method declares
ab.backend_matrix("sdpa")                          # who claims a fused path

    The columns are explained on the taxonomy page, and Backends explains why 28 of the 32 declare reference only.
