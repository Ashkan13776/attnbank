WHAT THIS MACHINE CAN RUN

attnbank backends on this machine (torch 2.10.0+cu128, cuda yes)
----------------------------------------------------------------
reference   available    plain PyTorch; always available; the correctness anchor
            version: 2.10.0+cu128
sdpa        available    torch SDPA; CUDA dispatches to FlashAttention-2 or mem-efficient
            version: 2.10.0+cu128
flash_attn  unavailable  the flash-attn package; CUDA, fp16/bf16 only
            reason: the flash_attn package is not installed
            fix:    pip install 'attnbank[flash]'   # needs CUDA and a C++ toolchain
xformers    unavailable  memory-efficient attention; detected, deliberately unused
            reason: no method declares it: torch >= 2.2 already routes `sdpa` to the same memory-efficient kernel, so a second path would add a dependency and a second thing to keep equal to the reference
            fix:    pip install 'attnbank[xformers]'
triton      unavailable  hand-written kernels; detected, deliberately unused
            reason: no method declares it: the bank ships no hand-written kernel, because these implementations are read against the paper (DESIGN.md Sec. 6)  (the package IS installed here)

default: 'reference'.  ab.build(name, backend=...) to choose; ab.backend_matrix() for which method supports which.
